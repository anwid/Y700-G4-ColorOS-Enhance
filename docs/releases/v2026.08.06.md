# Y700 四代 ColorOS 修复模块合集·2026-08-06

# ⚠️ 本 Release 不提供 `1-meta-overlayfs-v1.3.1-KSU.zip`

## meta-overlayfs 是独立第三方项目。请到 [KernelSU-Modules-Repo/meta-overlayfs Releases](https://github.com/KernelSU-Modules-Repo/meta-overlayfs/releases) 下载，不要在本项目索要、转存或询问该文件。

本次为联想拯救者 Y700 四代 ColorOS 移植 ROM 的首次合集发布。详细安装顺序、作用域、ROM 限制和卸载方法请阅读仓库首页，不要根据文件编号盲目全装。

## 发布资产

- `2-Y700-Gen4-ColorOS-Display-Fix-v1.3-KSU.zip`
  - 修复 @微微薇 OPPO Pad Mini 移植 ROM 的错误虚拟刘海与竖屏时间遮挡。
  - 依赖 meta-overlayfs；不要安装到 `@GUF296` ROM。
- `3-Y700-Gen4-ColorOS-Stock-Audio-v1.0-KSU.zip`
  - 恢复原厂有线耳机音量曲线/增益，停止无法初始化的 OPlus AudioX。
  - 依赖 meta-overlayfs。
- `4-Y700-Gen4-ColorOS-APK-Parse-Fix-v1.3-LSPosed.apk`
  - 修复部分合法 APK 被 ColorOS 误报 `-124`。
  - 需 Vector/LSPosed；作用域只选“系统框架”。
- `5-Y700-Gen4-ColorOS-Haptics-Control-v2.11-KSU.zip`
  - 分场景触感调整、标准效果、合成原语、Y700 双马达预设和可视化多段编排。
  - 需 Vector/LSPosed；作用域只选“系统框架”。
- `6-Y700-Gen4-ColorOS-Pen-Compatibility-v1.6.5-KSU.zip`
  - 联想 Tab Pen Plus 接入 ColorOS 原生手写笔链路。
  - v1.6.5 修复按钮桥对 `getevent` 标签大小写过于敏感、导致双击扫描码 `0601` 偶发未转发的问题；同时包含 v1.6.4 的无障碍服务自动恢复修复。
  - 需 Vector/LSPosed；作用域为“系统框架”和 `com.oplus.ipemanager`。
- `6.5-Y700-Gen4-ColorOS-Accessibility-Warning-Whitelist-v1.0.0-LSPosed.apk`
  - 仅对明确白名单应用跳过 ColorOS 无障碍十秒警告。
  - 需 Vector/LSPosed；作用域只选“系统框架”。
- `7-Y700-Gen4-ColorOS-Global-Round-Corners-Off-v1.5-KSU.zip`
  - 关闭 @微微薇 ROM 的全局软件圆角。
  - 同时需 meta-overlayfs 和 Vector/LSPosed；Xposed 作用域只选 SystemUI；不要安装到 `@GUF296` ROM。
- `8-Y700-Gen4-ColorOS-Stock-Thermal-v1.1-KSU.zip`
  - 恢复 TB322 ZUXOS 的 CPU、GPU、电池和 common 温控配置。
  - 依赖 meta-overlayfs；不修改刷新率、触控采样率、HAL、内核或 DTBO。
